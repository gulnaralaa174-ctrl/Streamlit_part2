# Streamlit_part2

Визуализация метеорологических данных в Streamlit.

**Цель:**

Разработать интерактивное веб-приложение с помощью Streamlit, которое позволяет анализировать и визуализировать исторические метеорологические данные.

**Исходные данные**

Вам предоставлен датасет, содержащий следующие столбцы:

avg_temp — средняя температура;

total_precip — общее количество осадков;

avg_wind — средняя скорость ветра;

is_rainy — бинарный/логический признак дождя.

**Краткое описание приложения**

Разработано интерактивное веб-приложение на базе Streamlit для анализа и визуализации исторических метеорологических данных. Приложение позволяет загружать данные из CSV-файла, выполнять фильтрацию, анализировать погодные показатели и строить интерактивные графики.

**Реализованные функции**

1. Загрузка и отображение данных
   
- Поддержка загрузки CSV-файла с метеоданными.

- Отображение данных в виде интерактивной таблицы.

- Возможность сортировки и просмотра данных.
  
2. Фильтрация данных
   
-Выбор одного или нескольких городов.

-Выбор диапазона дат через календарь.

-Автоматическое обновление таблиц и графиков после применения фильтров.

3. Создание новых признаков

Добавлены вычисляемые категории:

Категория температуры:

«Холодно»

«Умеренно»

«Жарко»

Уровень осадков:

«Небольшие»

«Сильные»

Комфортность погоды на основе температуры и скорости ветра.


**Как пользоваться приложением:**

1.Установка зависимостей

Установите необходимые библиотеки:

pip install -r requirements.txt

2.Запуск приложения

streamlit run app.py

После запуска приложение откроется в браузере автоматически.

3. Загрузка данных

Загрузите CSV-файл через боковую панель.

Если файл не загружен, будут использованы демонстрационные данные.

4.Работа с фильтрами

В боковой панели можно:

выбрать нужные города;

задать диапазон дат;

изменить отображаемые показатели.

5. Анализ данных

В приложении доступны:

таблица исходных данных;

статистические показатели;

графики распределения;

сравнение городов;

временные ряды и прогноз.

6. Экспорт результатов

Отфильтрованные данные можно скачать в формате CSV с помощью кнопки «Скачать CSV».
